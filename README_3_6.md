# Alpha 3.6 — Founders Flight playable local championship

Run `npm install && npm start`, then visit `http://localhost:8080/season.html`.

Three fixed simulator stages now launch directly from the season hub with preset scenery, seeds, weather and wind. Completing a race saves its best time to localStorage and unlocks the next stage. The hub shows a combined personal-best time, completion status, community leaderboard preview, and downloadable NFT trophy metadata draft. Existing Alpha 3.5 features are preserved.

**Security and limitations:** These are browser-local practice results, editable by users. They are NOT server-authoritative, anti-cheat verified, NFT prize eligible, or suitable for awarding real collectibles. NFT minting, distribution and marketplace purchases are not implemented. The API leaderboard remains self-reported. No real NFT is promised.
