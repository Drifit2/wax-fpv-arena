# Alpha 3.5 — Founders Flight season preview

Run `npm install && npm start`, then visit `http://localhost:8080/season.html`.

New: three selectable season challenge themes stored locally, existing multiplayer leaderboard preview at `/api/season/standings`, `/api/season/config`, AtomicHub link, and downloadable trophy metadata drafts.

**Limits:** Season challenge selection does not modify simulator tracks. Multiplayer results are client-reported and unverified; no prize eligibility, season scheduling, NFT minting, payouts, wallet transactions, or anti-cheat is implemented. No collectible has been created on chain.
