# Alpha 6.7 — Racing Clubs and Provisional Club Standings

Open `http://localhost:8080/clubs67.html` after `npm install && npm start`.

Features: wallet-authenticated club creation, open recruitment, 16-pilot member limit, unique names/tags, persistent roster, leaving clubs, and provisional club standings calculated from current tournament race results. A captain with other members cannot abandon a club; transfer and moderation are future work.

Limitations: clubs are open to anyone (no invite approval), one club per WAX account, no roster history, no cross-season historical scores, no NFT minting, no financial prizes. Only the current tournament's provisional server-simulated race history contributes to scores. No live multi-wallet or production security test completed.
