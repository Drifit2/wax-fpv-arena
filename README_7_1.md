# Alpha 7.1 — Team Championship Broadcast Desk

Run `npm install && npm start`, then visit `/team-championship71.html`. Read-only `/api/club71/championship` exposes fixture standings, live pilot telemetry, completed race events, and the active season name. The dashboard refreshes every 2.5 seconds, features fixture selection, automatically generated commentary and a cosmetic SVG banner preview.

**Important scope:** This release adds spectator coverage and a completed-fixture championship table to the existing sequential 1v1 best-of-three Club Wars system. It does **not** implement simultaneous 2v2 or 4v4 racing, relays, NFT minting, financial prizes, or production-verified racing. Live wallet and multi-device tests are outstanding.
