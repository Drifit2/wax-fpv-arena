# Alpha 4.4 — NFT Trophy Collection Manager

Adds `/collection-manager.html`: an offline AtomicAssets-oriented collection planning interface with five trophy edition concepts, proposed supply caps, collection/schema/template identifiers, optional recipient, IPFS CID checks, and downloadable administrator-review JSON manifests.

**No blockchain write actions:** No wallet signing, NFT minting, listing, transfer, reward eligibility, royalties, or commission collection. Edition supply caps are proposed, not enforced. Actual minting requires collection authorization, schema/template verification, artwork licensing, admin approval, independently audited race results, and secure wallet signing.

Run `npm install && npm start` and visit `http://localhost:8080/collection-manager.html`. All earlier features remain included.
