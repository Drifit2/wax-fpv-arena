# Alpha 6.9 — Club Wars

Run `npm install && npm start`; open `http://localhost:8080/club-wars69.html`.

- Wallet-authenticated captains challenge another club and select a pilot from their club roster.
- Challenged captain accepts and chooses their own pilot; schedules within the next 30 days.
- Captains attach **existing completed server-simulated ranked race IDs** after the scheduled time and acceptance; race participants must match the fixed lineups.
- Best of three, first to two victories; duplicate race IDs cannot be reused across Club Wars.
- Off-chain exhibition only; no verified rankings, token rewards, or NFTs minted.
- This is **not** automatic dedicated matchmaking. Pilots must race through the existing ranked mode and submit their result IDs.
- Live wallet and multiplayer testing remain outstanding.
